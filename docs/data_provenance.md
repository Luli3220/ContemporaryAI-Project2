# 数据来源与测量口径

本实验不使用外部公开数据集或真实地图。输入分为课程样例、人工构造的边界情况、固定种子的合成数据；性能数字来自真实程序运行。

## 1. 课程样例

原始依据为仓库根目录的《实验二要求_new.pdf》。迷宫、加权地图、博弈树和四宝藏地图按PDF录入，见 `experiments/cases.py` 和 `data/test_cases/course.json`。官方期望仅用于测试断言，不进入算法返回逻辑。

## 2. 正确性测试

`tests/`包括官方样例、人工边界、参数化随机案例和测量方法测试，共522项。原有随机基准保留，另增加60个地图的四方法BFS交叉验证、20个加权地图的FIFO检查，以及交错轮次、统计量和块bootstrap测试。一个测试项可内部检查多个方法，测试数不等于算法调用数。

独立验证链为：迷宫A*对BFS；加权A*对Dijkstra；Alpha-Beta对完整Minimax；宝藏搜索对独立动作排列穷举。参考实现位于 `experiments/references.py`，不调用生产路径搜索或宝藏状态转移。

## 3. 正式性能实验

| 类别 | 输入配置 | 配置实例数 | 原始测量行数 |
|---|---|---:|---:|
| 迷宫 | 4规模×4障碍率×20种子 | 320 | 1,920 |
| 加权地形 | 4规模×5场景×20种子 | 400 | 2,400 |
| 合成博弈树 | 3分支数×3深度×20种子 | 180 | 2,160 |
| 固定宝藏深度 | H=0..6，同一课程地图 | 7个深度配置 | 840 |
| 宝藏价值敏感性 | T1价值0..18的10个偶数×H2/H4，4种算法 | 20个价值/深度配置 | 2,400 |
| A*独立2×2消融 | 复用基础迷宫，2种启发函数×2种同分策略 | 原来的320张地图 | 3,840 |
| **合计** | 含算法对照与重复计时 | **不按行数视为独立样本** | **13,560** |

另有30次距离预计算和端到端计时，保存为routing_times.csv，不计入13,560行。消融重复使用基础地图，没有新增320张独立地图。

- 迷宫格子独立按障碍概率采样，只覆盖起终点为可通行；不删除不可达样本。
- 加权普通格为1/3/8，另有零权和障碍场景；概率与种子保存在CSV。
- 合成树的叶值为[-100,100]均匀随机整数。
- 地图每配置种子0–19，各方法重复3次。宝藏与敏感性各方法交错测量30轮，每轮固定种子打乱顺序。消融也按轮次交错。
- 所有生成器使用局部 `random.Random(seed)`。固定种子与参数可重建输入；无须下载数据。

## 4. 结果文件

results/raw保留逐次记录、每轮顺序、官方输出、环境、源码哈希和JUnit；results/tables包含实例中位数、因素对照、同轮耗时配对和区间；results/figures由这些数据绘制。每次运行有独立run_id，batch_manifest.json记录文件哈希，避免混用不同批次。

重复运行的时间会随硬件和调度变化；路径成本、根效用与确定性节点计数应当复现。随机合成分布与四宝藏小例子的结论不代表所有真实场景。
