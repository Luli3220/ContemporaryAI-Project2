# 最终实验方案

本轮保留四题的问题定义、公开接口和默认搜索顺序，仅增加队列排序消融与计时控制。以下统计规则在最终测量前确定。

## A* 2×2 消融

默认 `f_h_fifo=(f,h,seq,g,pos)`，新增 `f_fifo=(f,seq,g,pos)`。与零启发式、曼哈顿距离组成四种方法；每张地图四种方法按轮次交错测量，用BFS给出独立最优距离。

地图沿用4种规模、4种障碍概率、种子0–19，共320个原有实例。正式每方法3次，预热2轮；消融数据单独保存为maze_ablation.csv。记录expanded、generated、max_frontier和wall_ms，按可达性分组。

先对实例内重复取中位数，再计算四个配对对照：固定两种tie-breaking分别比较启发函数，固定两种启发函数分别比较tie-breaking；另外计算差分之差。种子级均值和减少率使用1000次bootstrap的95%区间。

## 宝藏交错计时

H=0..6及T1价值0,2,…,18、H=2/4均保留。各配置比较Minimax、原始/反向/即时收益排序Alpha-Beta。每个配置先预热2轮，随后正式30轮，每轮每种算法恰好运行一次。顺序种子由20261020、配置编号、轮次及阶段的SHA256派生，算法顺序、轮次和位置保存到原始CSV和measurement_order.csv。

stats创建、随机排序、结果解码和穷举核对在计时外；函数调用、输入检查和算法内部动作排序计入wall_ms。矩阵预计算单独测量，博弈搜索复用同一矩阵。保留runtime_ms作为算法主体计时。

对原始/反向、原始/启发式、反向/启发式做同轮配对。报告两方法中位数、中位数之差、每轮差值中位数、时间比和更快轮次比例。置信区间采用5000次配对轮次bootstrap，并补充长度3的循环块bootstrap，以观察短期调度相关性的影响。

差值定义为候选方法减基线方法，小于0表示更快。预先将“稳定更快”定义为：至少20轮、两种95%差值区间上界均小于0，且候选更快的轮次至少占75%。该判断只描述当前机器和固定配置的重复计时。

## 同批数据与独立验证

每轮完整或快速实验生成独立run_id，原始测量带run_id，batch_manifest.json保存原始数据、表格、图表及报告的SHA256。审计核对源码哈希、记录数量、独立最优值、重复计数、交错顺序、统计重算和文件哈希。报告数值只读取本批CSV。

CI使用Python3.11，依次安装固定版本依赖、运行完整pytest、验证官方样例、执行quick实验并审计输出。本地从独立目录和Python3.11环境执行同样流程。完整实验作为正式数据单独运行。
